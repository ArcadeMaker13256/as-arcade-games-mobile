A'S ARCADE GAMES — GITHUB MOBILE STATIC QA REPORT
=================================================
Edition: 7.0-web

LIMITATIONS
-----------
• This is a static browser/PWA adaptation, not a direct conversion of the
  Windows Python/Tkinter games. All 190 launcher entries are included, but they
  share a smaller set of mobile game engines and are not exact one-for-one ports.
• Automated browser execution could not be completed in the current container
  because its Chromium process did not terminate normally. JavaScript syntax,
  file references, data integrity, image validity and feature wiring were
  checked statically. Test on Safari and Chrome after publishing.
• Player data is local to each browser/device and does not sync through GitHub.
